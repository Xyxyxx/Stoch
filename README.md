# Stoch
Project to learn about and apply stochastic calculus. We will be following the approach given by Thomas Björk given in his *Arbitrage Theory in Continuous Time*. Hence the idea of this project is to learn some financial mathematics as well as basic stochastic calcululs.

Much of this project are contained in various notebooks explaining the basic theory and simulations of SDEs. As such it requires a conda environment to funciton. One can setup the required notebook using ```environment.yml```.
